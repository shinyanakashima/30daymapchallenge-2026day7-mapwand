# MapWand

回して、押して、10分で地図をつくる道具。#30DayMapChallenge 2026 Day 7「10 minute map」の作品です。

M5StickC Plus に Hat Mini EncoderC を載せた手元のダイヤルで、ブラウザ上の都道府県別の統計地図（2020年国勢調査の5指標）を編集し、出典付きの PNG として保存します。地理院タイルのベースマップと、鉄道・人口集中地区・県庁所在都市・主要都市の人口のレイヤーを重ねられます。デバイスがなくても、画面のボタンとキーボードで同じ編集と保存ができます。

```
Hat Mini EncoderC ─I²C─ M5StickC Plus ─BLE GATT─ Web Bluetooth ─ Web アプリ（地図の描画・分類・書き出し）
```

## 「10分」の範囲

- 事前に用意したもの：このデバイスとアプリ、統計データと境界データの前処理、6 種類のスタイルなどの候補。
- 10分に含めるもの：画面の『制作開始』を押してから、仕上げで保存を確定するまでの地図の編集。
- 接続・データ読み込み・機材の設定は事前準備で、10分に含めません。装置の開発時間が10分だったわけではありません。

10分を過ぎても編集は続けられます。タイマーは超過時間を赤で表示し、保存した時点の制作時間を PNG と一緒に書き出す設定 JSON（`elapsedMs`）に記録します。

## 必要なもの

| 用途 | もの |
| - | - |
| 地図の編集 | Windows PC と Chrome または Edge（Web Bluetooth 対応版） |
| 手元の操作 | M5StickC Plus（Plus2 ではない）、Hat Mini EncoderC、USB-C ケーブル |
| ビルド（任意） | Node.js 22 以上、Python 3.11 以上、PlatformIO Core 6.2 |

Safari と Firefox では Bluetooth 接続を使えません。その場合も画面操作モードで編集と保存ができます。

## 1. Web アプリを動かす

```bash
cd web
npm ci
npm run dev
```

ブラウザで `http://localhost:5173/` を開きます。Web Bluetooth は HTTPS か localhost でだけ動きます。

本番用のビルドは `npm run build`（出力は `web/dist/`）。GitHub Pages へは `.github/workflows/pages.yml` で配信できます（リポジトリ設定の Pages で「GitHub Actions」を選ぶ）。

## 2. デバイスにファームウェアを書き込む

Hat Mini EncoderC を M5StickC Plus の上部ヘッダーに差し込み、USB で PC につなぎます。どちらかの方法で書き込みます。

### A. ビルド済みファイルを使う（ツールのインストール不要）

1. Chrome で [ESP Tool（esptool-js）](https://espressif.github.io/esptool-js/) を開く。
2. Baudrate を 921600 にして Connect を押し、M5StickC Plus のシリアルポートを選ぶ。
3. Flash Address を `0x0`、ファイルに `firmware/prebuilt/mapwand-m5stickc-plus-merged.bin` を指定して Program を押す。
4. 終わったら M5StickC Plus の電源ボタン（左側面）を 6 秒押して切り、2 秒押して入れ直す。

ファイルの SHA-256 は `firmware/prebuilt/mapwand-m5stickc-plus-merged.bin.sha256` にあります。

### B. ソースからビルドして書き込む

```bash
pip install platformio==6.2.0
```

```bash
cd firmware
pio run -t upload
```

ポートが自動で見つからない場合は `pio run -t upload --upload-port COM5` のように指定します。シリアルログは `pio device monitor` で見られます（115200bps）。

起動すると画面に `MapWand` → `WAITING PC` が出て、ダイヤルの LED が青くゆっくり点滅します。`NO DIAL` と出る場合は Hat の差し込みを確認してください（1 秒ごとに再試行します）。

## 3. 接続する

1. PC の Bluetooth をオンにする。
2. Web アプリ右側の『MapWandに接続』を押す。
3. ブラウザの機器選択に出る `MapWand` を選んで「ペア設定」を押す。

右上が「接続中のMapWand」になり、M5 の画面に現在の項目と値が出れば準備完了です。ダイヤル 1 クリックで候補が 2 つ動く、または動かない場合は『ダイヤル設定』の「1候補あたりのカウント」を変えます。回転方向が逆なら「回転方向を反転」をオンにします。

## 4. 操作

| デバイス | キーボード | 動作 |
| - | - | - |
| ダイヤルを回す | ← → | 今の項目の候補をすぐ試す（未採用のプレビュー） |
| ダイヤルを押す | Enter / Space | 試している候補を採用して次の項目へ |
| ダイヤルを長押し（0.8 秒） | Backspace / Esc | 未採用の候補を取り消す。もう一度で直前の採用を取り消す |
| 正面のボタン（A） | ↓ | 次の項目へ（未採用の候補は取り消す） |
| 側面のボタン（B） | ↑ | 前の項目へ（未採用の候補は取り消す） |

電源ボタンは編集に使いません。画面右のボタンと項目一覧でも同じ操作ができます。

編集項目は次の順です。データを選び、スタイルで全体を決めたら、あとは必要なところだけ調整します。スタイルを採用すると、配色・境界線・地名・ベースマップがそのスタイルの標準に切り替わります。

| 項目 | 候補 |
| - | - |
| データ | 人口密度・人口増減率・平均世帯人員・人口性比・高齢化率 |
| スタイル | 白地・和紙・夜・雪・新聞・若草 |
| ベースマップ | なし・淡色地図・標準地図・白地図・陰影起伏図・写真（地理院タイル） |
| 配色 | 柿・藍・夕焼・若葉・紫・墨（いずれも値が大きいほど濃い。夜は大きいほど明るい。人口増減率は 0 を境に増加側をこの色、減少側を別の系統にする） |
| 階級 | 分位分類 3〜7 階級 |
| 境界線 | 極細・細・標準・太・極太 |
| 地名 | 地名なし・主要地名（8 都道府県と値）・全都道府県名 |
| レイヤー | なし・県庁所在地・主要都市の人口・鉄道・人口集中地区・鉄道＋県庁所在地・人口集中地区＋鉄道・すべて |
| 構図 | 全景・余白広め・寄り |
| タイトル | 用意した 4 案から選ぶ（データ名が入る） |
| 仕上げ | 保存する・編集へ戻る |

### 制作の流れ

1. 接続を済ませ、『制作開始』を押す（ここから 10 分を計る）。
2. スタイルから順に、回して選び、押して採用する。
3. 仕上げで「保存する」を押す。PNG（1600×1200）のダウンロードが始まり、「保存準備完了」が出る。
4. 自動でダウンロードされなかった場合は、パネルの『PNG を保存』を押す。同じ地図を再現する設定は『設定 JSON』で保存できる。

保存した設定 JSON は『設定を開く』で読み込めます。

## 困ったとき

| 症状 | 対処 |
| - | - |
| 「Bluetooth 無効」と出る | PC の Bluetooth をオンにして、もう一度『MapWandに接続』を押す |
| 機器選択に MapWand が出ない | M5 の画面が `WAITING PC` か確認。別の PC やタブに接続中なら切断する。M5 を再起動する |
| 「許可されていません」と出る | ブラウザのサイト設定で Bluetooth を許可する。HTTPS か localhost で開いているか確認する |
| 途中で切断した | 編集内容はそのまま残ります。3 秒ごとに自動で再接続し、だめなら『再接続』を押す |
| M5 の画面が `NO DIAL` | Hat を差し直す。ピンが曲がっていないか確認する |
| 「プロトコルが一致しません」 | Web アプリと同じ版のファームウェアを書き直す |
| 動かなくなった | M5 の電源ボタンを 6 秒押して切り、入れ直す。Web はページを再読み込みし、設定 JSON から復元する |

## データと出典

| 項目 | 内容 |
| - | - |
| 統計 | 総務省統計局「令和2年国勢調査 人口等基本集計」第1-1表（statInfId 000032142402）・第2-3表（000032142406）（e-Stat）。2020 年 10 月 1 日現在 |
| 人口密度 | 人/km²。表の値。面積は国土地理院「令和2年全国都道府県市区町村別面積調」、調査対象外地域の面積を除いて統計局が算出 |
| 人口増減率 | %。2015 年→2020 年の 5 年間。表の値 |
| 平均世帯人員 | 人/世帯。一般世帯人員 ÷ 一般世帯数（施設等の世帯を除く） |
| 人口性比 | 女性 100 人に対する男性の数。表の値 |
| 高齢化率 | %。65 歳以上人口の割合（年齢「不詳」を除く）。第2-3表の値 |
| 境界 | 国土交通省「国土数値情報（行政区域データ）」N03 2020 年（令和2年1月1日時点） |
| 鉄道 | 国土交通省「国土数値情報（鉄道データ）」N02 2020 年度。ケーブルカーを除き、新幹線とそれ以外に分けて表示 |
| 人口集中地区 | 国土交通省「国土数値情報（人口集中地区データ）」A16 2020 年 |
| 都市の位置 | Wikidata（CC0）。県庁所在都市と人口 50 万以上の市の代表点。主要都市の人口は第1-1表 |
| ベースマップ | 地理院タイル（国土地理院）。表示時に読み込み、選んだタイルの出典を地図に自動で入れる |
| 加工 | 市区町村を都道府県コード 2 桁で統合し表示用に簡略化。小笠原諸島・沖ノ鳥島・南鳥島と 1km² 未満の島は表示しない。沖縄県は枠内に移動 |
| 図法 | Webメルカトル図法（地理院タイルと同じ。北ほど面積が大きく表示される） |

出典の表記：

- 総務省統計局「令和2年国勢調査 人口等基本集計」（政府統計の総合窓口 e-Stat, https://www.e-stat.go.jp/）を加工して作成
- 「国土数値情報（行政区域データ・鉄道データ・人口集中地区データ）」（国土交通省）（https://nlftp.mlit.go.jp/ksj/）を加工して作成
- 地理院タイル（https://maps.gsi.go.jp/development/ichiran.html）
- Wikidata（CC0）

統計と国土数値情報は政府標準利用規約に準拠し、CC BY 4.0 と互換です（人口集中地区データは国土数値情報の利用規約で商用可）。取得 URL、ファイルのハッシュ、加工内容は [data/manifest.json](data/manifest.json) と [data/README.md](data/README.md) にあります。
