# 実機確認の手順

ここまでの確認はビルドと模擬デバイスでの通しまで。以下は実機でしか確かめられない項目。結果は表の「結果」欄に記入する。

## 準備

1. Hat Mini EncoderC を M5StickC Plus の上部ヘッダーに差す（向きは Hat の表示に合わせる）。
2. README の「2. デバイスにファームウェアを書き込む」で書き込む。
3. Windows PC で Chrome か Edge を開き、`web` を `npm run dev` で起動して `http://localhost:5173/` を開く。
4. 『MapWandに接続』から MapWand を選ぶ。
5. ログを見ながら確かめる場合は USB をつないだまま `pio device monitor` を開く（Web Bluetooth と同時に使える）。

## 確認項目

| # | 確認すること | 期待する結果 | 結果 |
| - | - | - | - |

| 4 | 右回し | 候補が「次」へ進む（逆なら『ダイヤル設定』で反転し、既定値の変更を検討） | |

## 実演の収録

1. 接続を済ませ、Web の『制作開始』を押す。
2. スタイルから仕上げまで、デバイスだけで編集して保存する。
3. 画面収録と手元の撮影を同時に行う。保存した PNG と設定 JSON（`elapsedMs` に制作時間）を残す。

公開時の説明には、事前に用意したもの（デバイス・アプリ・データの前処理・候補）と、10 分に含めたもの（『制作開始』から保存まで）を書く。
